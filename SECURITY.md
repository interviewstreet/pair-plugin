# Reporting security issues

Please report suspected vulnerabilities privately to **security@hackerrank.com**, the contact published in [HackerRank's responsible disclosure policy](https://www.hackerrank.com/trust/security/).

Include the affected Pair plugin/CLI version, operating system, a description of the impact, and minimal reproduction steps using a disposable repository and synthetic data. Do not include access tokens, private source code, raw agent conversations or other users' personal data in public GitHub issues.

If you suspect a credential was exposed, revoke or rotate it through the issuing provider. Do not send the credential itself in the report; identify its provider and the affected file or operation instead. Follow the published policy's scope and reporting rules. This document does not authorize testing outside that scope.

For non-security setup issues, run `paircli status` and consult [the onboarding guide](docs/ONBOARDING.md). Review and redact any logs before sharing them.
